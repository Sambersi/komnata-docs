# Проверка конфигурации

Команда `komnata check-config` проверяет файл конфигурации и завершает работу.
Она добавлена в версии 2.0.

## Файл по умолчанию

```bash
komnata check-config
```

Без параметра `--config PATH` используется файл `./komnata.yaml` в текущей папке.

## Другой файл

```bash
komnata check-config --config /etc/komnata/komnata.yaml
```

Передайте путь к нужному файлу параметром `--config`.

## Проверка перед запуском

Перед запуском [сервиса](usage.md) рекомендуется проверить [конфигурацию](configuration.md).
Это рекомендация руководства, а не обязательное условие работы команды.

!!! note "Границы описания"
    Исходные данные не определяют формат сообщений, коды завершения и полный перечень проверок.
    Автоматическое исправление и флаг `--fix` в справке не описаны.
