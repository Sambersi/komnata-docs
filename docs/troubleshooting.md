# Решение проблем

## Порт занят

Если сообщение при запуске указывает, что порт занят, проверьте, не использует ли его другой процесс.
Задайте другой `port` в [конфигурации](configuration.md) или остановите конфликтующий процесс средствами операционной системы.
Для версии 2.0 порт по умолчанию — `8000`.
Это общая рекомендация диагностики; точный текст сообщений продукта в исходных данных не задан.

## Ошибка в файле конфигурации

Проверьте нужный файл перед запуском сервиса:

```bash
komnata check-config --config /etc/komnata/komnata.yaml
```

Для файла `./komnata.yaml` в текущей папке достаточно `komnata check-config`.
Проверьте имена и значения параметров по разделу [Настройка](configuration.md).
Параметр `cache_ttl` удалён в версии 2.0.
Формат диагностических сообщений и коды завершения в исходных данных не описаны.
Подробности команды приведены на странице [Проверка конфигурации](check-config.md).
