# Установка

## Требования

Для komnata 2.0 нужен Python 3.10 или новее.

## Получение программы

Komnata — вымышленный продукт учебного проекта.
Исходные данные не описывают способ получения пакета и не подтверждают его публикацию в PyPI.
Поэтому команда установки здесь не приводится: способ доставки следует уточнить у разработчика.

## Первый запуск

Если программа уже предоставлена, сохраните конфигурацию из раздела [Настройка](configuration.md) как `komnata.yaml` в текущей папке.
Запустите сервис:

```bash
komnata serve
```

Для конфигурации по умолчанию адрес сервиса — `http://127.0.0.1:8000`.
Если изменены `host` или `port`, используйте соответствующий адрес.
Порядок создания администратора в исходных данных не описан; его следует уточнить у разработчика.
