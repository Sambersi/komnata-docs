# Работа с сервисом

## Запуск

Для обычного запуска выполните:

```bash
komnata serve
```

Для запуска в фоновом режиме используйте флаг `--background`:

```bash
komnata serve --background
```

Чтобы указать файл конфигурации, передайте его путь:

```bash
komnata serve --config /etc/komnata/komnata.yaml --background
```

В версии 2.0 команда `start` переименована в `serve`, а флаг `--daemon` заменён на `--background`.

## Проверка конфигурации

Перед запуском можно проверить файл командой [check-config](check-config.md).
Проверка завершается без запуска сервиса.

## Остановка и перезапуск

Остановите процесс сервиса средствами операционной системы и запустите его снова.
Доступные параметры перечислены в разделе [Настройка](configuration.md).

## Версия программы

```bash
komnata version
```

Команда показывает версию программы.

## Вход в веб-интерфейс

Откройте адрес сервиса в браузере.
Для параметров по умолчанию используйте `http://127.0.0.1:8000`.
Механизм входа и получения прав в исходных данных не описан; уточните его у разработчика.
