Настройка
=========

Сервис читает параметры из файла ``./komnata.yaml`` при запуске.
Путь к файлу можно изменить параметром ``--config PATH``.

Перед применением изменённого файла:

* проверьте конфигурацию командой :doc:`check-config`;
* остановите процесс сервиса средствами операционной системы;
* запустите сервис с нужным файлом конфигурации.

.. list-table:: Параметры конфигурации
   :header-rows: 1
   :widths: 35 45 20

   * - Параметр
     - Описание
     - По умолчанию
   * - ``host``
     - Адрес, на котором сервис принимает подключения
     - ``127.0.0.1``
   * - ``port``
     - Порт подключения
     - ``8000``
   * - ``database``
     - Путь к файлу базы данных
     - ``./komnata.db``
   * - ``booking.max_duration_hours``
     - Максимальная длительность одной брони, ч
     - ``4``
   * - ``booking.allow_weekends``
     - Разрешить бронирование в субботу и воскресенье
     - ``false``
   * - ``notifications.email_enabled``
     - Отправлять подтверждения брони по электронной почте
     - ``false``

Пример файла с параметрами по умолчанию:

.. code-block:: yaml

   host: 127.0.0.1
   port: 8000
   database: ./komnata.db
   booking:
     max_duration_hours: 4
     allow_weekends: false
   notifications:
     email_enabled: false

.. note::

   После изменения конфигурации перезапустите сервис.
   Параметр ``cache_ttl`` удалён в версии 2.0 и в этой конфигурации не используется.

Как перезапустить сервис, описано в разделе «Работа с сервисом»: :doc:`usage`.
