# Самостоятельная проверка вместо недоступного парного ревью

Это проверка автора с помощью ИИ, а не отзыв khvost1k.
Решение независимого рецензента отсутствует.

| Аспект | Файл и место | Замечание | Решение |
|---|---|---|---|
| Техническая точность | docs/check-config.md, пример другого файла | В приложении А использован --file; cli-help допускает --config PATH | Исправлено на --config |
| Полнота | docs/configuration.md, таблица параметров | Нужен notifications.email_enabled со значением false | Добавлена строка |
| Понятность | docs/troubleshooting.md, раздел ошибки конфигурации | Общего совета недостаточно: нужна команда для конкретного файла и вариант по умолчанию | Добавлены оба варианта |
| Стиль | docs/usage.md, раздел входа | «Залогиниться» и «кликнуть» заменяются понятным описанием; наличие кнопки входа не подтверждено | Описан переход по адресу, неизвестный механизм обозначен |

Пример предложения правки к строке из исходного черновика (не отправлен от имени другого человека):

```suggestion
komnata check-config --config /etc/komnata/komnata.yaml
```

Этот блок показывает синтаксис suggestion, но не подменяет комментарий к строке PR напарника.
В исходной документации команды start/--daemon действительно неверны для 2.0; в итоговой версии присутствует serve/--background.
